# ArcaneEcoQuest 🌳✨

Game petualangan web edukatif tentang lingkungan hidup. Selamatkan desa Celestria dengan memilih salah satu dari tiga karakter penyihir!

## 🎮 Karakter

**🌱 Kael** - Penyihir Tumbuhan  
Menanam pohon di SkyForest

**💧 Lyra** - Penyihir Air  
Membersihkan sungai dan memberikan air pada tanaman

**☀️ Selene** - Penyihir Matahari  
Mengumpulkan mana untuk memberikan energi sinar matahari

## 🎯 Tujuan
Selamatkan Pohon Lumorra yang layu dan pelajari tentang ekosistem!

## 🛠️ Teknologi
- HTML5, CSS3, JavaScript
- Audio dan Video untuk efek suara

## 🚀 Cara Bermain

1. Buka file `interface.html` di browser
2. Tekan F11 untuk fullscreen
3. Pilih karakter dan mulai petualangan!

## ✨ Fitur
- Musik dan efek suara
- Cutscene dan animasi
- Gameplay edukatif tentang lingkungan
- 3 karakter dengan misi berbeda
